About the System

Smart Reservations
for Your Barangay

Barangay Reserve is a mobile-based system that allows residents to book barangay facilities, manage reservations, and apply authentication-based discounts through a secure platform.

This project was developed as an academic capstone project for facility management in Philippine barangays.

Authentication & Verification Workflow

Our comprehensive authentication system includes:

  • Gmail Authentication: Separate login/register flows with account selection
  • Profile Configuration: Guided setup for new users with required fields
  • Verification Types: Three-tier system with different discount rates
  • Auto-Fill System: Cross-screen data synchronization
  • Security Features: JWT tokens and session management

Advanced Booking System

Our intelligent booking management includes:

  • Real-time Availability: Live facility scheduling and overlap checking
  • Booking Rejection: Fake payment and insufficient payment detection
  • 3-Strike Ban System: Automatic penalties for violations
  • Official Tools: Quick booking and facility management
  • Mobile Integration: Full Android Flutter app with backend connectivity
